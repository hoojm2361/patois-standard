# Contributing

## Proposing a change to the standard

1. Open a **Discussion** if you're exploring an idea — "how should we
   spell X?" — with examples from your own writing.
2. If the discussion converges on a proposal, open an **Issue** with
   the proposed rule and the evidence for it.
3. When the group is ready to commit, open a **Pull Request** to
   `STANDARD.md` with the specific addition or change. The PR
   description should link to the Issue and Discussion.
4. If approved, the PR is merged and a line is added to `DECISIONS.md`.

## What makes a good proposal

- **Attested in real usage** — cite examples from your own writing or
  from published Patois sources
- **Consistent with existing rules** — if it contradicts a previous
  decision, propose amending that decision, not silently overriding it
- **Accessible to a non-linguist reader** — if it requires explaining
  IPA symbols, explain them

## Code of conduct

This is a Jamaica-diaspora community project. Be specific in
disagreement, generous in interpretation, and honest about what you
don't know. No decision is final; the log exists so we can revisit.
